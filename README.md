# Student Management System Using Arrays

## Project Overview

The Student Management System is a browser-based application developed to demonstrate the real-world application of arrays as a data structure.

The system manages student records such as student IDs, names, and marks using arrays.

---

## Real-World Application

This project represents a student record management system used in schools and universities.

Educational institutions need to store and manage many student records efficiently. Arrays provide a simple way to organize and access this information.

---

## How Arrays Are Used

The application uses three arrays:

### Student IDs Array

Stores student identification numbers.

Example:

studentIDs[0] = "PS/ITC/24/0001"


### Student Names Array

Stores student names.

Example:

studentNames[0] = "Kwame Mensah"


### Student Marks Array

Stores student marks.

Example:

studentMarks[0] = 78

---

## Why Arrays Are Necessary

Arrays are necessary because they:

- Store multiple values under one variable name
- Allow quick access using indexes
- Make searching and updating data easier
- Organize related information efficiently

---

## Features

- Add students
- Search students
- Edit student records
- Delete students
- Calculate average, highest and lowest marks
- Store data using arrays
