How Arrays Are Used

Arrays are used to store multiple values of the same type under one variable name.

This application uses arrays to store student information:

  • studentIDs[] stores student identification numbers
  • studentNames[] stores student names
  • studentMarks[] stores student marks

Example: 


studentIDs[0] = "PS/ITC/24/0001"

studentNames[0] = "Kwame Mensah"

studentMarks[0] = 78
